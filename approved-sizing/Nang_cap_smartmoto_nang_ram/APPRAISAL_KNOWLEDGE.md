## 💡 TRI THỨC RÚT RA (GOLDEN PATTERN)

### RAM upgrade strategy

**Approved approach:**
```
SmartMotor system → RAM upgrade needed

Pattern:
  1. Identify performance bottleneck (RAM)
  2. Calculate current vs required RAM
  3. Propose incremental upgrade
  4. Document baseline metrics

Key principle:
  - Memory is first bottleneck
  - Upgrade based on actual usage metrics
  - No over-provisioning
```

### Supplement sizing methodology

**Current + Additional:**
```
Baseline:
  - System already deployed
  - Performance issues identified
  - Measurement-based justification

Add-on sizing:
  - Δ RAM = Required - Current
  - NOT: Total RAM from scratch
  - Focus on gap filling
```
