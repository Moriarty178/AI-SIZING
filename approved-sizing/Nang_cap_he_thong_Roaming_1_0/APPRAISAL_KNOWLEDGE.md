## 💡 TRI THỨC RÚT RA (GOLDEN PATTERN)

### Roaming system upgrade

**Approved approach:**
```
Roaming 1.0 system → Capacity/performance upgrade

Pattern:
  1. Analyze current roaming workload
  2. Project growth for new version
  3. Size for scalability
  4. Focus on telecom-specific requirements

Key considerations:
  - Inter-carrier connectivity
  - Protocol compatibility (MAP, CAP, etc.)
  - Signaling channel requirements
  - Fault tolerance mandatory
```

### Telecom system sizing

**Telecom-specific factors:**
```
Critical for Roaming:
  - Signaling traffic (SS7, diameter)
  - Data throughput (GTP tunnels)
  - Low latency requirements
  - High availability (99.999% target)
  - Protocol conversion overhead

Sizing approach:
  - Not just CPU/RAM
  - Focus on network throughput
  - Redundancy is mandatory
  - Geographic distribution
```
