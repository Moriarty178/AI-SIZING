> **Trạng thái:** đang thu thập. Đây là file làm việc của mục 0.1–0.4 trong
> [`PLAN.md`](../PLAN.md). Khi danh sách được xác nhận, mới số hóa sang

> xác nhận**. Code có thể đang sai so với tài liệu tiêu chí. Mỗi dòng phải được
> đối chiếu với tài liệu gốc rồi đánh dấu ở cột "Xác nhận".

- **Mã quy tắc:** `<NHÓM>-<số>` — `KPI`, `SCL` (scale), `CPU`, `RAM`, `DSK`,
  `SRV`, `MDB` (MariaDB), `RDS` (Redis), `KFK` (Kafka), `K8S`, `LBF` (LB/FW),
  `PRC` (quy trình), `EVD` (sở cứ).
